Research Methodology

This dashboard presents findings from analysis of 1.2 million Spotify tracks spanning 100 years (1920-2020), examining the relationship between tempo and danceability.

Audio Features

14 features extracted: tempo, energy, danceability, valence, acousticness, instrumentalness, liveness, speechiness, loudness, duration, year, key, mode, time signature

analytics Analysis Methodology

1. Tempo Categorization

Tracks grouped into 5 tempo zones based on music theory and psychoacoustic research:

  • • < 80 BPM: Slow/Ballad zone
  • • 80-100 BPM: Moderate zone
  • • 100-120 BPM: Sweet Spot (optimal danceability)
  • • 120-140 BPM: Upbeat/Club zone
  • • > 140 BPM: Fast/Electronic zone

2. Statistical Analysis

Danceability scores compared across tempo zones using mean, median, and standard deviation. Hypothesis testing performed with 95% confidence interval.

3. Machine Learning Models

Trained 4 prediction models on 100,000 tracks using scikit-learn:

  • • Random Forest Regressor: Popularity prediction (R²=93.1%)
  • • Random Forest Classifier: Hit/Flop classification (Acc=92.9%)
  • • Gradient Boosting: Danceability prediction (R²=66.7%)
  • • Random Forest: Tempo optimization (R²=19.4%)
