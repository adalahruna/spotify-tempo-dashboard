# 🚀 QUICK START: Convert Proposal ke Word

> **Panduan super cepat 15 menit untuk format proposal di Word**

---

## ⚡ **LANGKAH CEPAT (Copy This!)**

### **Step 1: Setup Document (3 menit)**

```
1. Buka Microsoft Word
2. File → New → Blank Document
3. Layout → Size → A5
4. Layout → Margins → Custom:
   - Left: 2.5 cm
   - Top: 2.5 cm  
   - Right: 2 cm
   - Bottom: 2 cm
   → OK
```

---

### **Step 2: Set Default Font (1 menit)**

```
1. Home → Font (klik panah kecil di pojok)
2. Font: Book Antiqua
3. Size: 10
4. ✓ Set As Default
5. → All documents based on Normal template
6. → OK
```

---

### **Step 3: Set Paragraph Default (1 menit)**

```
1. Home → Paragraph (klik panah kecil)
2. Settings:
   - Alignment: Justified
   - Indentation: Special → First line → 1.27 cm
   - Spacing: Before 0 pt, After 6 pt
   - Line spacing: Multiple → 1.15
3. ✓ Set As Default
4. → All documents
5. → OK
```

---

### **Step 4: Modify Heading Styles (2 menit)**

**Heading 1 (untuk BAB I, BAB II, dll):**
```
1. Home → Right-click "Heading 1" → Modify
2. Formatting:
   - Font: Book Antiqua, 12 pt, BOLD
   - Alignment: Center
   - Spacing: Before 12pt, After 12pt
3. → OK
```

**Heading 2 (untuk A. Latar Belakang, B. Rumusan, dll):**
```
1. Right-click "Heading 2" → Modify
2. Formatting:
   - Font: Book Antiqua, 11 pt, BOLD
   - Alignment: Left
   - Spacing: Before 12pt, After 6pt
3. → OK
```

**Heading 3 (untuk 1. Karakteristik Audio, dll):**
```
1. Right-click "Heading 3" → Modify
2. Formatting:
   - Font: Book Antiqua, 10 pt, BOLD
   - Alignment: Left
   - Spacing: Before 6pt, After 6pt
3. → OK
```

---

### **Step 5: Create Cover Page (3 menit)**

```
1. Type atau copy-paste cover text dari PROPOSAL_WORD_READY.txt
2. Center all text (Ctrl+E)
3. Format:
   - Logo UNESA: Insert → Pictures (size 3-4 cm)
   - Judul: 14 pt BOLD
   - Subtitle: 11 pt
   - Nama: 12 pt
   - Footer: 12 pt BOLD
4. Add page break (Ctrl+Enter)
```

---

### **Step 6: Copy Main Content (5 menit)**

```
1. Buka PROPOSAL_TUGAS_AKHIR_UNESA.md
2. Copy BAB I section
3. Paste ke Word (gunakan Ctrl+Shift+V untuk paste without formatting)
4. Apply Heading 1 ke "BAB I PENDAHULUAN"
5. Apply Heading 2 ke "A. Latar Belakang", "B. Rumusan", etc.
6. Repeat untuk BAB II dan BAB III
```

**Tips:** Jangan copy semua sekaligus! Copy per section lalu format.

---

### **Step 7: Insert Table of Contents (1 menit)**

```
1. Halaman setelah cover → ketik "DAFTAR ISI"
2. Apply Heading 1 ke "DAFTAR ISI"
3. Enter, new line
4. References → Table of Contents → Automatic Table 1
5. Done!
```

**Update TOC:** Right-click → Update Field → Update entire table

---

### **Step 8: Page Numbering (2 menit)**

**Section 1 (Cover - TOC): Roman i, ii, iii**
```
1. Posisi di cover page
2. Insert → Page Number → Bottom of Page → Plain Number 2
3. Double-click nomor → Format Page Numbers → Roman (i, ii, iii)
```

**Section 2 (BAB I dst): Arabic 1, 2, 3**
```
1. Posisi di awal BAB I (BEFORE text)
2. Layout → Breaks → Next Page (buat section baru)
3. Double-click header area BAB I
4. Klik "Link to Previous" (unlink dari section sebelumnya)
5. Insert → Page Number → Top of Page → Plain Number 3
6. Format → Start at: 1
```

---

### **Step 9: Format Special Elements (2 menit)**

**Code Blocks:**
```
1. Select code text
2. Font: Courier New 9 pt
3. Shading: Light Gray
4. Borders: All Borders
```

**Formulas:**
```
1. Insert → Equation
2. Type formula
3. atau paste LaTeX-style
```

**Tables:**
```
1. Insert → Table
2. Header row: BOLD + Gray background
3. Borders: All solid lines
```

---

### **Step 10: Final Check (2 menit)**

```

✓ Margins correct
✓ Font Book Antiqua 10pt
✓ Line spacing 1.15
✓ Justified alignment
✓ Heading styles applied
✓ Table of Contents inserted
✓ Page numbers correct
✓ No typos
```

## 💡 **PRO TIPS**

### **Tip 1: Use Styles, Don't Manual Format**
❌ Don't: Select text → Bold → 12pt → Center
✅ Do: Apply Heading 1 style

**Why:** Automatic TOC, consistent formatting, easy updates

---

### **Tip 2: Navigation Pane**
```
View → ✓ Navigation Pane
```
**Benefit:** See document outline, jump between sections easily

---

### **Tip 3: Show Formatting Marks**
```
Home → ¶ (Show/Hide button)
```
**Benefit:** See spaces, tabs, page breaks → easier to debug formatting

---

```
Ctrl+S every 5 minutes

```

---

```

- ✓ Margins correct

- ✓ No orphan/widow paragraphs
- ✓ Alignment consistent
```

## 🔧 **TROUBLESHOOTING**

### **Problem: Font keeps changing back**
**Fix:** Make sure you clicked "Set As Default" → "All documents based on Normal template"

---

### **Problem: Paragraph indent inconsistent**
**Fix:** 
1. Select all (Ctrl+A)
2. Ctrl+Q (clear paragraph formatting)
3. Reapply default paragraph style

---

### **Problem: Page numbers wrong**
**Fix:**
1. Check section breaks (should have one before BAB I)
2. Double-click header/footer
3. Ensure "Link to Previous" is OFF for BAB I section
4. Format page numbers separately for each section

---

### **Problem: Table of Contents not updating**
**Fix:**
1. Right-click TOC
2. Update Field
3. Update entire table
4. If still wrong, check if headings have correct styles applied

---

### **Problem: Too much space between paragraphs**
**Fix:**
1. Select text
2. Home → Paragraph
3. Spacing After: 6 pt (not "Auto" or large number)
